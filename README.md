## 1. Project Overview
A premium, production-quality, futuristic, and fully responsive 3D corporate website engineered for **SYSTEQ India** (SYSTEQ Facility Management & Security Services (India) Private Limited), headquartered in Bengaluru, Karnataka, India.

This project delivers a high-impact corporate web presence featuring:
- **Cinematic 3D WebGL Architectural Visualizations** via Three.js
- **4-Scene High-Definition Video Slider** with crossfading and mobile fallback
- **Interactive 3D Perspective Tilt Cards**
- **Lenis Smooth Scrolling** synchronized with GSAP ScrollTrigger
- **Animated 5-Step Working Process Timeline**
- **Interactive 3D WebGL Security Trust Shield**
- **Verified Corporate Data, Leadership & Client Metrics** (zero fabricated claims)
- **100% Frontend-Only Architecture** with reusable modular PHP includes

## 6. Performance & Quality Benchmarks
- **Asset Optimization:** WebP image fallback, compressed MP4 videos with poster images, lazy loading.
- **Three.js Lifecycle Management:** `IntersectionObserver` automatically halts the WebGL render loop when the hero or shield is out of the viewport, preserving GPU and battery resources.
- **Accessibility & Reduced Motion:** Full `prefers-reduced-motion` compliance across video playback, smooth scrolling, and 3D tilt.
- **Zero Horizontal Overflow:** Guaranteed on all screen sizes down to 320px.
